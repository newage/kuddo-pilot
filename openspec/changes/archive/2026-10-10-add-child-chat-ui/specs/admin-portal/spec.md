# Spec Delta

## Purpose

Мінімальний портал адміністратора для керування користувачами, ролями, вчителями та доступами ролей до вчителів.

## ADDED Requirements

### Requirement: Доступ лише для admin
Система SHALL пускати в admin-портал лише користувачів із роллю `admin`.

#### Scenario: Користувач без ролі admin
- **WHEN** користувач з роллю `user` відкриває сторінку admin-порталу
- **THEN** доступ відхиляється

### Requirement: Керування ролями
Система SHALL дозволяти admin переглядати користувачів і призначати їм роль `admin` або `user`.

#### Scenario: Призначення ролі
- **WHEN** admin призначає роль користувачу без ролі
- **THEN** користувач отримує доступ відповідно до ролі

### Requirement: Керування вчителями
Система SHALL дозволяти admin створювати, редагувати й деактивувати вчителів (назва, предмет, системний промпт).

#### Scenario: Деактивація вчителя
- **WHEN** admin деактивує вчителя
- **THEN** вчитель зникає зі списку для нових чатів

### Requirement: Керування доступами
Система SHALL дозволяти admin задавати, яким вчителям доступна кожна роль.

#### Scenario: Надання доступу
- **WHEN** admin додає вчителя до доступів ролі `user`
- **THEN** користувачі з роллю `user` бачать цього вчителя
