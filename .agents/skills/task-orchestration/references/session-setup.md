# Підготовка сесії

Доповнює [`SKILL.md`](../SKILL.md), крок 1. Робиться раз за сесію, перед першим планом. Повторно — лише коли змінився інструмент чи набір моделей або користувач попросив.

## Можливості інструмента

| Можливість | Навіщо | Якщо немає |
|---|---|---|
| запуск субагента з брифом | основа протоколу | підзадачі послідовно сам |
| модель на субагента | рівні складності | рівні лишаються для розбиття й глибини перевірки; модель одна на всіх |
| паралельний запуск | хвилі | хвиля йде послідовно; перерахуй час |
| фон і сповіщення про завершення | працювати, поки агенти працюють | чекати кожного |
| продовження того самого агента | доробка з контекстом помилки | новий агент: бриф + пункти DoD, що не пройшли |
| режим лише читання | інвестигейт, рев'ю, архітектура | заборона запису в брифі |
| таймер або події | статус раз на хвилину | статус при кожному поверненні керування; чекпойнти субагента у файлі |
| зупинка агента | довгий агент без прогресу | чекати й попередити користувача |

Звідки брати: адаптер інструмента в [`../adapters/`](../adapters/), якщо є; інакше — документація й довідка самого інструмента. Можливість, яку не вдалося підтвердити, вважай відсутньою і скажи про це.

## Таблиця рівнів

1. **Моделі.** Які моделі інструмент дозволяє призначати субагентам — з документації, довідки CLI, конфігу чи самого параметра запуску.
2. **Ціни.** Один раз — з офіційної сторінки цін постачальника або його API моделей. Сторонні агрегатори не джерело: вони відстають. Сторінка переїхала (404) — знайди актуальну адресу на сайті постачальника. Немає мережі чи офіційне джерело недоступне — відносний порядок за позиціонуванням моделей у лінійці постачальника і позначка «ціни не перевірено».
3. **Розкладка.** Рівень 1 — найшвидша й найдешевша модель, придатна до роботи з інструментами. Рівень 2 — збалансована. Рівень 3 — найсильніша стандартна модель лінійки. Преміальні моделі понад неї — окрема найпотужніша лінія, дорожча за флагман, — субагентам не призначаються.
4. **Контекст.** Запиши вікно контексту: модель з малим вікном не годиться для читання великого корпусу, навіть якщо рівень підходить.
5. **Обмеження.** Правила проєкту чи користувача щодо моделей мають пріоритет над розкладкою.

Кілька постачальників в одному інструменті — одна таблиця на всіх: рівень визначають можливості й ціна, а не бренд.

На підписці замість оплати за токени ціна показує, в якій пропорції модель витрачає ліміт; порівняння рівнів від цього не змінюється.

## Формат блоку в чаті

```markdown
Інструмент: <назва> — субагенти так, модель на агента так, паралель так, фон так, статус через <механізм>.

| Рівень | Модель | Ціна за 1M токенів, вхід / вихід | Контекст |
|---|---|---|---|
| 1 | <модель> | <ціна> | <вікно> |
| 2 | <модель> | <ціна> | <вікно> |
| 3 | <модель> | <ціна> | <вікно> |

Джерело: <сторінка цін>, <дата>. Не призначаються: <моделі понад рівень 3>.
```
