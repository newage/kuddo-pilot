# Рівні складності

Доповнює [`SKILL.md`](../SKILL.md), крок 5: там рівні й базові правила, тут — як оцінити рівень і кому який. Конкретна модель рівня береться з таблиці рівнів сесії ([`session-setup.md`](session-setup.md)).

## Сигнали

| Сигнал | Рівень 1 | Рівень 2 | Рівень 3 |
|---|---|---|---|
| опис | повний: готовий код, точна команда, зразок | прозою, в межах наявних патернів | неоднозначний, треба вирішувати |
| обсяг | 1–2 файли або однотипна правка в багатьох | кілька файлів одного модуля; великий корпус на читання | кілька модулів, наскрізне правило |
| судження | немає: транскрипція, пошук за точним запитом | вибір у межах патерну, інтерпретація доказів | дизайн, компроміси, синтез |
| помилка | ловиться командою одразу | ловиться тестами чи рев'ю | тиха — ризикові зони з кроку 5 |
| зворотність | тривіально відкотити | відкочується | дорого або неможливо |
| середовище | дія без побічного ланцюга | дія тягне ланцюг: кодогенерація, міграція, кеш, збірка | ланцюг зачіпає дані чи інших споживачів |

Рівень визначає найвищий сигнал, а не середній.

## Роль → рівень

Таблиця — нижня межа: ризикові зони з кроку 5 піднімають будь-яку роль до рівня 3.

| Роль | Рівень |
|---|---|
| пошук і збір фактів за точним запитом | 1 |
| читання й стиснення великого корпусу | 2, модель з достатнім контекстом |
| виконавець з повним описом чи готовим зразком; пакет однотипних правок | 1 |
| виконавець за прозовим описом; інтеграція | 2 |
| виконавець наскрізної зміни чи ризикової зони | 3 |
| рев'юер | 2; 3 — для логіки, безпеки, конкурентності й ризикових діфів |
| перевіряльник знахідок | 2 — правила й вимоги; 3 — логіка й безпека |
| перевіряльник гіпотези | 2; 3 — якщо гіпотеза тонка або від неї залежить дороге рішення |
| автор концепту, критик концепту | 3 |
| декомпозиція, DoD, синтез, фінальне рішення | оркестратор, не делегується |

## Effort

Якщо інструмент дозволяє задати субагенту рівень міркування (effort, reasoning): механіка — низький, рівень 2 — середній, рівень 3 — високий і вище.

Перш ніж знижувати модель для підзадачі із судженням, спробуй сильнішу модель на нижчому effort: на нових моделях низький effort часто дає не гірший результат, ніж попереднє покоління на високому.
